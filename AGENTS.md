# Project workflow

When a game is completed, run the relevant checks, commit the finished game and related hub changes, and push them to `main` in `https://github.com/Jason2043/Mini-Games.git`. The user has requested this automatically for every completed game; do not ask for confirmation each time.

Preserve remote history and unrelated work. Do not force-push. Verify the remote commit before reporting that a game is saved to GitHub.
